# Lia (fili-ai), the assistant itself

You are asked about the assistant's own window. Its commands: `fili-ai ctl action NAME` (`fili-api show fili-ai` lists them), `fili-ai ctl state` (open, focused, attention, busy). Sessions and history belong to `fili-ai-daemon` (`fili-ai sessions`). Settings: `~/.config/filigrane/fili-ai.toml` (mode, width, follow). Never edit the history files by hand.
